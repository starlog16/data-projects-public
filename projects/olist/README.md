# Olist 电商履约与经营分析

## 业务问题

1. 订单从下单到送达通常需要多久，晚到比例如何？
2. 已送达订单的商品金额、月度趋势和商家贡献如何？

## 数据

- 订单表：99,441 行、8 列；订单号唯一。
- 明细表：112,650 行、7 列；98,666 笔订单、3,095 个商家；订单号+明细序号唯一。
- 775 笔订单没有明细；找不到订单的明细 0 行。
- 原始数据来自 Olist 公开电商数据；本仓库不镜像原始 CSV，需按 NOTICE.md 自行下载到 `data/raw/`。

## 方法

- Pandas 读取两表，检查主键、粒度、缺失、重复和双向覆盖。
- 已送达 96,478 笔；8 笔缺少实际送达时间。
- 下单至送达耗时 = 实际送达时间 - 下单时间，按 24 小时/天折算；可计算样本 96,470 笔。
- 晚到 = 实际收货日期 > 预计送达日期（只比较年月日）；同日不算晚到。
- 明细先按订单聚合，再左连接回订单表，避免 1:N 连接导致金额/行数倍增；775 笔无明细保持空值，不填成真实零金额。
- 状态、月度、商家汇总通过 DuckDB SQL 生成，并用 Pandas 独立复算对账。

## 主要结果

- 已送达 96,478 笔，占全部订单 97.02%。
- 已送达订单商品金额 13,221,498.11 雷亚尔，运费 2,202,965.54 雷亚尔。
- 平均送达 12.56 天，中位 10.22 天，P90 23.10 天，最大 209.63 天。
- 晚到 6,534 笔，占 96,470 的 6.77%；晚到订单平均晚到 10.62 天，中位 7 天。
- 2,970 个有已送达明细的商家；Top 10 商品金额占 13.27%；按金额排序前 20% 商家占 82.29%（派生计算，按 seller_summary 排序）。

## 输出

- `data/processed/status_summary.csv`：8 种订单状态的订单数、金额、占比。
- `data/processed/monthly_summary.csv`：按下单月份的已送达订单数、商品金额、运费、平均每单金额。
- `data/processed/seller_summary.csv`：商家维度金额/订单数/明细数。
- 完整订单级宽表 `order_analysis.csv` 约 19MB，未放入仓库；运行脚本可重新生成。

## 运行


需要先把原始订单/明细 CSV 放到 `projects/olist/data/raw/`。

## 限制

- 商品金额是 GMV 口径，不含运费，不是平台收入或利润；没有支付/退款表。
- 订单状态是历史快照，不称转化率。
- 775 笔无明细、8 笔缺送达时间、长耗时记录均保留待核，不静默删除。
- 没有客户地理、评价、支付数据，不推断地区差异、满意度或真实损失。
